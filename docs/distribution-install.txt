Nivlet — install and recover

Nivlet is free. No account, licence or payment is needed.
This candidate contains an Apple-silicon app. macOS 14 is the provisional floor;
runtime compatibility and final release acceptance still require testing.

Install a signed, notarized release
1. Open the DMG and drag Nivlet into Applications.
2. Eject the image. Open Nivlet from Applications.
3. Nivlet lives in the menu bar and at the screen edge; it has no Dock icon.

A file labelled LOCAL-UNNOTARIZED or SIGNED-UNNOTARIZED is an internal candidate,
not a trusted public download. Do not disable Gatekeeper to install it.
If macOS rejects a published release, keep your library and use the previous
trusted release while the distributor fixes the download.

Manual update
1. Export all pockets from Nivlet and keep the export somewhere private.
2. Resolve any visible save error, then quit Nivlet from its menu-bar menu.
3. Keep the previous signed installer. Back up the complete local library while
   Nivlet is closed (including assets, recovery data and database sidecar files).
4. Open the new signed, notarized DMG and replace Nivlet in Applications.
5. Eject the image, open the installed copy and check prompts, references and notes.

Recovery
- If the replacement fails before first launch, keep or reinstall the previous
  trusted app. Replacing the app does not require deleting its local library.
- If launch or migration fails, preserve the complete library and the error.
  Never delete the library to make the app start.
- A previous app may refuse a newer library schema. Do not force it open or copy
  an old database into a live library. Restore a complete pre-update backup while
  the app is closed, keeping the failed/current library separately for recovery.
- A pre-migration SQLite snapshot alone is not a complete backup of originals or
  later edits. See the developer distribution guide for the recovery procedure.
- Portable exports restore as new pockets, with a preview; they do not silently
  replace the current library. Save errors and recovered drafts need explicit review.

Working tools stay local and offline. Copy means copied to the clipboard.
You choose what to paste or attach to another application.
