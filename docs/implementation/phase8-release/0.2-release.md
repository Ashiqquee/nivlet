## Change and source

Older pending-save journals omit the completion-time map introduced for to-do expiry. The decoder now accepts that older format, preserving the pending pocket collection for explicit review and Retry. This fixes a library-open failure that blocked pocket navigation. See [recovery evidence](../phase2-persistence.md).
