# Nivlet 0.2 reference shelf replacement — 2 November 2026

The owner requested replacing the unused 0.2 download, keeping version 0.2, publishing both repositories, and removing the installed app and its local data for a fresh reinstall. The replacement uses internal build **9**. The prior [build 8 record](0.2-release.md) remains historical evidence.

## Behavior

- Removed the entire import-status area: no importing loader, saved summary or successful-import toast above the shelf.
- Actual failures and large-file confirmations retain per-file Retry, Choose again and Import anyway in a separate recovery sheet.
- Shelf and inspector show a single editable label, with no duplicate original filename. Clicking a shelf label opens the editor; the label field has a visible input boundary.
- A local label draft supports Select All → Delete → replacement text. Valid edits autosave; a blank field restores its last valid label on leaving it. Original filenames and bytes are unchanged.
- The recovery-journal regression fixture now uses whole-second deletion timestamps. Its former `.now` value could compare unequal after Date/Unix-epoch conversion at submicrosecond precision; a separate 10,000-conversion check reproduced 4,873 unequal values. No recovery implementation changed.
